Sanger Trace Trimmer

Trim low-quality ends from Sanger base calls using the Mott algorithm; inspect Q20/Q30 and ambiguity statistics.

Local browser processing · No uploads

Input & parameters

ABI/AB1 (PBAS/PCON entries) or four-line FASTQ (Phred+33). Maximum 10 MB.

A selected file takes precedence over pasted text.

The Mott algorithm maximizes the cumulative difference between the cutoff error probability and per-base error probability. It can retain internal low-quality positions.

Interpretation & privacy


Start/end coordinates are zero-based with an exclusive end. QC percentages apply to retained bases; reads without a passing region have length zero. The application does not re-call chromatogram peaks, align a vector reference, or validate a clinical diagnosis.


All file parsing, calculations, and downloads occur within your browser. No data is sent to a server. The Python command-line interface provides equivalent FASTQ and optional AB1 processing for batch work.
